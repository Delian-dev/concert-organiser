# 🎶 Concert Management System

A **Java OOP Swing application** for organizing and managing multiple concerts. This app allows event managers to control all aspects of a concert including performers, sponsors, ticket holders, and event locations. It features a graphical user interface with intuitive navigation and data validation.

## 🎯 Main Features

This application simulates the workflow and data management required for organizing music concerts. It allows you to:

- Add, view, update, and delete concert-related entities.
- Associate musicians and sponsors to specific concerts.
- Track ticket sales and view client info.
- Manage venues and locations where concerts are held.

---

## 👥 Client Management

- View a list of registered clients (ticket buyers).
- Add new clients with name, email, and phone validation.
- Update client details through a dedicated update form.
- Delete clients from the database.

---

## 🎤 Musician Management

- View all musicians.
- Add new musicians with detailed information.
- **Differentiate between musician types**, such as solo performers and band members.
- Update musician data as needed.
- Remove musicians from the system.

---

## 💼 Sponsor Management

- List and manage sponsors for concerts.
- Add new sponsors with market value info.
- Update existing sponsor information.
- Remove sponsors when no longer needed.

---

## 🎟️ Ticket Management

- View ticket data and associated clients.
- Track which clients have purchased tickets for which concerts.
- Display detailed ticket information per concert.

---

## 🎭 Concert Management

- Create new concerts and assign relevant data (sponsors, performers, tickets sold).
- View all existing concerts.
- Update concert details such as the date, venue or capacity.
- Delete concerts from the system.

---

## 🌍 Locations and Countries

- Add new locations where concerts take place.
- View the list of all available venues.
- Link locations to specific concerts.

---

## 🔗 Entity Associations

- **Associate musicians** to specific concerts to form lineups.
- **Associate sponsors** to concerts for financial or promotional support.
- See which musicians and sponsors are connected to which concerts.
